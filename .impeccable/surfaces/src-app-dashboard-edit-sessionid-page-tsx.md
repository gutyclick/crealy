# Editor conversacional — Fase 5

- **Scope:** Espacio privado para editar imágenes por conversación y conservar versiones.
- **Mode:** Operate.
- **Audience:** Creador, emprendedor o equipo social que necesita iterar una pieza sin empezar de cero.
- **Job:** Observar una imagen, pedir un cambio concreto, comparar el resultado y elegir la próxima base.
- **Primary task:** Crear una nueva versión mediante una instrucción breve.
- **Proof/content:** Imagen real, conversación persistente, historial recuperable, comparación y descarga privada.
- **Constraints:** Un cambio activo por usuario, URLs firmadas, límites explícitos, teclado, reducción de movimiento y adaptación desde 320 px.
- **Direction:** Estudio mate negro; lienzo amplio, conversación fija y #DDF527 sólo para acciones y estados activos.
- **Memorable moment:** La nueva versión entra con un barrido nítido sobre el lienzo mientras el historial permanece estable.
- **Unresolved:** Aplicación de la migración Fase 5 y variables de edición en Vercel.
