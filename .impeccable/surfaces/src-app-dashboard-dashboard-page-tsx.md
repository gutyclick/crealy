# Dashboard — Fase Beta 8.1

- **Scope:** Inicio privado del producto y acceso rápido al sistema de generación consolidado.
- **Mode:** Operate.
- **Audience:** Creadores, emprendedores y equipos pequeños que crean, supervisan y reutilizan piezas visuales.
- **Job:** Iniciar una pieza, seguir trabajos activos y recuperar resultados o ediciones con el mínimo de decisiones.
- **Primary task:** Elegir crear o editar; después seleccionar uno de seis productos visuales válidos.
- **Proof/content:** Perfil, saldo, plan, cola, generaciones y sesiones reales; los fallos de consulta se declaran y nunca se convierten en ceros ficticios.
- **Constraints:** Dark studio, `#DDF527` solo para acción/selección/listo, URLs firmadas, responsive desde 320 px, motion CSS y `prefers-reduced-motion`.
- **Direction:** Mesa de producción mate con jerarquía editorial, hero abstracto local y superficies continuas en lugar de un mosaico de tarjetas genéricas.
- **Memorable moment:** Tres láminas de formatos se mueven como piezas sobre una mesa mientras la persona decide entre crear y editar.
- **Unresolved:** Ninguna decisión visual bloqueante; la prueba real de imagen depende de credenciales locales válidas de OpenAI.
